SOFT SKILLS ASSIGNMENT READER — VERCEL DEPLOYMENT

Files:
- index.html: searchable browser reader with week filter and expandable explanations
- assignment.json: extracted assignment content used by the reader
- Soft_Skills_July_2025_Assignment_Explained.docx: formatted Word document download

Deploy:
1. Upload these files/folder to a GitHub repository.
2. In Vercel choose Add New Project and import that repository.
3. Framework Preset: Other. Build Command: leave blank. Output Directory: . (root).
4. Deploy. Do not upload only index.html; keep assignment.json and the DOCX in the same root folder.

Note: This is a reading/study layout of the supplied PDF. Review the converted DOCX for any source-PDF extraction quirks before submitting it as an official assignment.
